# 05 存储分发（环 5）

## 5.1 这一环解决什么问题

清洗完的 Markdown 落到哪？**2 种去向**：

| 去向 | 适用 | 落点 |
|---|---|---|
| `local_md` | 默认（绝大多数场景） | 本地知识库目录 |
| `screen_only` | 临时查询 / 调试 | 不落盘 |

**环 5 = 决定去哪 + 怎么落**。

> 如果你需要落到其他团队协作工具，可以在此基础上自行扩展一个去向，参考 `local_md` 的 schema 结构补一份对应的路径模板和鉴权配置即可。

## 5.2 核心 Schema

```yaml
storage:
  destination: local_md | screen_only
  path_template: ...
  retention_days: 30
  license_warnings:            # 涉及版权的强制警告
    - image_commercial: false
    - x_post_quote: limit_50_chars
  post_actions:                # 落盘后的附加动作
    - notify_user: true
```

## 5.3 2 种去向详解

### 5.3.1 local_md（默认）

**硬约束**：
- **所有采集结果固定落 `<YOUR_VAULT_PATH>/anysearch库/` 根目录，扁平单文件，不建子文件夹**（`<YOUR_VAULT_PATH>` 替换成你自己的知识库根目录）
- **一轮搜索对话 = 一个 markdown 文件**：这一轮里不管跑了几条 query、几次工具调用，所有结果依次写进同一个文件，不因多条记录拆成多个文件，也不因为想区分"清洗前/清洗后"而建 raw/cleaned 子目录
- **文件名 yymmdd 前缀**（如 `260721_AI新动向_reddit.md`），直接放在 `anysearch库/` 下
- **顶部必须有 yaml 表头**，沉淀采集日期/平台/关键字等关键信息

**路径模板**：

```yaml
local_md:
  base: "<YOUR_VAULT_PATH>/anysearch库/"
  # 一轮采集 = 一个文件，直接落在 base 根目录下，不建子目录
  file: "{base}YYMMDD_{主题短名}.md"
  # 示例（把 <YOUR_VAULT_PATH> 换成你自己的路径）
  example: "<YOUR_VAULT_PATH>/anysearch库/260721_AI新动向.md"
```

**单文件约束**：
- 一轮搜索对话（不管调了几次工具、几条 query）= 一个 markdown 文件
- 不允许"100 条结果写 100 个文件"，也不允许"一个根目录 + raw/cleaned 两个文件"
- 所有结果依次写进同一文件，按 Score/时间等排序
- 元信息块在文件顶部，结果列表在下方；工具真实调用的过程记录（命令、耗时）可作为文件内的一个小节一并写入，不必单独存 raw 文件

**yaml 表头模板**（所有落盘文件必须带）：

```yaml
---
# 采集元信息（必填）
collected_date: 2026-07-21              # 采集日期
platform: reddit                        # 平台（reddit/x/zhihu/weibo/wechatmp/...）
keywords:                               # 采集用的 keyword 列表（具体化后的）
  - "AI news in the last 72 hours"
  - "AI breakthrough July 2026"
domain: social_media                    # AnySearch 域
sub_domain: social_media.social_media   # AnySearch 子域
sdp_type: reddit_post                   # sdp 的 type 参数
max_results_per_query: 5                # 每条 query 的 max_results
total_queries: 2                        # 本次共跑了几条 query
total_results: 25                       # 去重后总结果数
anysearch_cost_ms: 9365                 # 总耗时
source: AnySearch CLI                   # 工具来源
fetched_at: 2026-07-21 14:30:00 (UTC+8) # 完成时间

# 翻译层信息（必填，体现翻译决策）
translation:
  intent_type: path_b                   # path_a / path_b / hybrid
  keyword_strategy: specific_phrase     # 具体化策略
  time_window:                          # 时间窗处理（如有）
    requested: "72h"
    filter_strategy: failed
    note: "social_media sdp 不支持时间参数"

# 清洗信息（必填）
cleaning:
  dedup_method: url+author_hash
  sort_by: score
  sort_order: desc
  ai_suspected_count: 0
  ai_suspected_rate: 0.0
  anonymity_risk: high                  # low/medium/high

# 存储信息（必填）
storage:
  file: "<YOUR_VAULT_PATH>/anysearch库/260721_AI新动向.md"
  retention_days: 0                     # 0 = 永久保留
---
```

**文件组织**：所有采集结果统一扁平落在 `anysearch库/` 根目录下，不建任何子文件夹（含 raw/cleaned/images）。一轮采集的真实调用过程（命令、耗时）作为文件内小节写入，不单独存 raw 文件。

**优势**：本地 Markdown 可被 Obsidian 等笔记工具或上层 skill 直接读取，永久保留；扁平结构下用户和上层 skill 都能在同一目录里一眼扫到所有采集文件，不用逐层进子文件夹找。

### 5.3.2 screen_only（不落盘）

**适用**：
- 临时查询（"帮我看一下 X 上今天 AI Agent 的热度"）
- 调试 / 验证
- 一次性消费的数据

**强制规则**：
- `retention_days: 0`（不存）
- 屏幕输出必须自带元信息五件套（与 local_md 一致）

## 5.4 路径契约

路径模板是 Skill 维护的核心资产。**不建议手动改路径**——路径错了上层 skill 找不到。

**统一根路径**：`<YOUR_VAULT_PATH>/anysearch库/`，扁平单文件，不建子文件夹。

```yaml
# assets/path_templates.yaml
local_md:
  base: "<YOUR_VAULT_PATH>/anysearch库/"
  # 所有场景统一：一轮采集 = 一个文件，直接落根目录
  file: "{base}YYMMDD_{主题短名}.md"
```

## 5.5 License 警告（涉及版权的强制约束）

```yaml
license_warnings:
  # 配图场景
  - trigger: "image_commercial=false"
    action: warn_user
    message: "本批含 🔴 不可商用图，仅供学习；公众号/小红书/抖音请勿使用"
  - trigger: "image_license_unknown"
    action: skip_save
    message: "License 未知 → 不入商用库"

  # X/Reddit 引用场景
  - trigger: "x_post_quote"
    action: limit_quote
    message: "X 推文引用上限 50 字，避免被 X ToS 警告"

  # 微信公众号文章引用
  - trigger: "wechatmp_full_text"
    action: summary_only
    message: "公众号全文复制有版权风险，存摘要 + 原文链接即可"
```

## 5.6 落盘后附加动作

```yaml
post_actions:
  notify_user: true            # 通知用户落盘完成
  log_to_run_history: true     # 写入 nook-search 自己的运行历史
  emit_metric:                 # 写入指标
    - name: search_count_by_day
    - name: platform_distribution
    - name: license_distribution
```

## 5.7 示例：配图素材合规采购

```yaml
storage:
  destination: local_md
  path_template: "<YOUR_VAULT_PATH>/anysearch库/260720_AI主题封面_配图.md"
  retention_days: 0           # 素材库永久保留
  license_warnings:
    - trigger: "image_commercial=false"
      action: warn_user
  post_actions:
    - notify_user: true
    - emit_metric: license_distribution
```

输出示例（节选）：

```markdown
# 配图素材清单 — AI Agent 主题封面

🟢 CC0 商用图（12 张）
  1. ![](...) | 作者：... | 来源：Unsplash | License: CC0
  2. ...

🟡 CC BY 需署名（5 张）
  1. ![](...) | 作者：... | License: CC BY 4.0（需署名）
  ...

🔴 不可商用（3 张，已过滤不入库）
  ...

总计：20 张查询 → 12 张 CC0 可用 + 5 张需署名 + 3 张过滤
```

## 5.8 与其他环的契约

- **环 4 输出（清洗后 MD）= 环 5 输入**
- **环 5 输出（落盘文件/屏幕）= 上层 skill 消费**
