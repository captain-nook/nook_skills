# 02 参数路由（环 2 — 翻译层）

## 2.1 这一环解决什么问题

意图解释后，Skill 拿到了结构化的 `required_fields` + 翻译层输出的 `translation` 字段。**环 2 = 把 fields + translation 翻译成 AnySearch 的 domain / sub_domain / sdp / keyword 组合**。

核心资产是 `assets/domain_map.yaml`（目标类型 → 域组合）。Skill 维护这张表，AnySearch 升级只改这张表，上层零感知。

## 2.2 核心 Schema

```yaml
route:
  queries:           # 1-N 条 query
    - id: 1
      query: "AI Agent tutorial"          # 纯自然语言，结构化参数走 sdp
      domain: "social_media"              # Path B 必填；Path A 留空
      sub_domain: "social_media.social_media"
      sdp: "type=zhihu,keyword=AI Agent tutorial"
      keyword: "AI Agent tutorial"        # 具体化 keyword（多词短语）
      path: path_b                        # path_a / path_b / hybrid
      max_results: 5                      # 默认 5，深度调研才用 10
      why: "中文深度长文，看 AI Agent 在中文圈的讨论深度"
    - id: 2
      query: "AI Agent framework comparison"
      domain: "social_media"
      sub_domain: "social_media.social_media"
      sdp: "type=x_top,keyword=AI Agent framework comparison"
      keyword: "AI Agent framework comparison"
      path: path_b
      max_results: 5
      why: "海外 AI 圈快讯，看全球最新讨论"
  total_count: 2     # ≤ 5（batch_search QPS 限制）
  fallback:          # 主域失败时的备选
    - replace: id:1
      with: ...
  strategy: parallel # parallel / serial / mixed
```

## 2.4 路由规则

### 2.4.1 官方 Path A/B 选路（live API instructions 原文）

**Path A（通用搜索，一等公民默认）**：
- 调用形态：`search(query="...")` 或 `batch_search(queries=[...])`，**不传 domain**
- 适用：新闻/概念/人物/公司/URL 验证/最新事件/对比/观点/任何没有结构化标识符的查询
- 官方原文："This is a first-class default — not a fallback or rare exception."

**Path B（垂直搜索）**：
- 调用形态：先 `get_sub_domains(domains=[...])`，再 `search` 带 `domain/sub_domain/sub_domain_params`
- 适用：结构化标识符（ticker/DOI/CVE/IATA/坐标/专利号等），或映射到专门垂类（股价/航班/论文/药品/天气/汇率/地理 POI）
- 硬规则：**NEVER call search with domain/sub_domain/sub_domain_params unless get_sub_domains was called first**

**Hybrid（拿不准时）**：
- 同一个 batch_search 里 1 个 Path A + N 个 Path B
- 官方原文："Coverage beats guessing."

### 2.4.2 keyword 具体化（硬规则 12）

**禁用单泛词**：`AI` / `科技` / `新闻` / `教程` / `Python` / `小红书` / `Reddit` 等单字或泛词

**必须多词短语或专有名词**：
- ✅ `AI large models`（官方示例）
- ✅ `Python developer`（官方示例）
- ✅ `Musk`（专有名词，官方示例）
- ✅ `AI Agent tutorial` / `Claude vs GPT coding` / `AI regulation healthcare`

**官方依据**：`sdp.keyword` 字段描述 "Search keywords take precedence over query fields"——keyword 会覆盖 query 位置参数，所以 keyword 写得好不好直接决定返回结果质量。

**具体化策略详见** [01_意图解释_澄清规则.md § 1.3.2](01_意图解释_澄清规则.md)。

### 2.4.3 首次使用某 domain 必须先调 get_sub_domains（硬规则 13）

**官方硬规则原文**：
> "NEVER call search with domain/sub_domain/sub_domain_params unless get_sub_domains was called first in this context."
> "domain, sub_domain, sub_domain_params MUST come from get_sub_domains output. NEVER guess."

**执行方式**：
- 首次使用某 domain 时，先调 `get_sub_domains(domains=[<domain>])` 确认 sdp 参数名与可选值
- 结果可 session 内缓存（同一 session 内同 domain 不重复调）
- 缓存失效条件：AnySearch 升级 / 跨 session / 用户明确要求刷新

### 2.4.4 多域 rephrase（官方 Pattern 2，同主题跨域时用）

**触发条件**：一个主题跨多个域（不是多个独立话题）

**策略**：batch_search 每个域**同一个核心问题换角度**，不是把用户原话塞每个域

**官方示例**：
> 主题："AI regulation's impact on healthcare investment"
> - finance 视角：`"AI regulation impact on healthcare investment trends 2025"`
> - health 视角：`"healthcare AI regulatory compliance requirements"`
> - legal 视角：`"AI medical device regulation legal framework"`

**对比 Pattern 1（并行域，多个独立话题）**：
> "Tell me about Tesla stock AND the latest COVID vaccine news"
> → 两个独立 query：finance (Tesla) + health (vaccine)，每个域不同 query

### 2.4.5 时间窗降级处理（硬规则 15）

**识别时间窗词**：72h / 24h / 本周 / 最近 N 天 / latest / recent / today / now

**三层降级实现**：

| 层 | 实现 | 适用 |
|---|---|---|
| ① 翻译层 | 把时间词写进 query 自然语言（"AI news in the last 72 hours"） | 所有域通用 |
| ② 参数层 | 话题相关时优先用带时间参数的域 | finance.quote/news（period）/ academic.search（year_from） |
| ③ 呈现层 | 按 published_at 硬过滤；若无则标 `time_window_check: FAILED` | 结果有 published_at 字段时 |

**social_media 域的硬约束**（live API 实测）：
- `get_sub_domains --domain social_media` 返回参数只有 `type / keyword / region` 三个
- **没有** time/hours/window/period/since/until/after/before/date_range 等任何时间参数
- `type` 里的 `x_latest` / `x_top` 是 feed 排序模式，不是时间窗口
- 处理方式：必须走 ① + ③（query 自然语言 + 呈现层标注 FAILED）

**finance 域的 period 参数**（live API 实测）：
- 支持 `7d/14d/30d/90d/180d/1y/5y` 或自定义 `{N}d`
- 适用 sub_domain：finance.quote / finance.macro / finance.calendar / finance.fundamental / finance.news
- 处理方式：走 ②（直接传 period 参数）

**academic 域的 year_from/year_to**（live API 实测）：
- 支持 `YYYY` 或 `YYYY-MM-DD` 格式
- 适用 sub_domain：academic.search / academic.preprint / academic.citation / academic.dataset / academic.biomedical
- 处理方式：走 ②（直接传 year_from/year_to 参数）

### 2.4.6 单 query 单域

每条 `query` 只能绑定一个 `domain` + 一个 `sub_domain`（AnySearch CLI 限制）。多域需求必须拆成多条 query。

### 2.4.7 batch_search ≤ 5 路

超 5 路必须分批：

```yaml
route:
  batches:
    - batch_id: 1
      queries: [q1, q2, q3, q4, q5]
      interval_s: 0
    - batch_id: 2
      queries: [q6, q7, q8]
      interval_s: 3   # 隔 3 秒避免 QPS 堆积
```

### 2.4.8 sdp 必须校验

sdp 是 `key=value,key=value` 字符串，key 名必须和 AnySearch live API `get_sub_domains` 返回的一致。错误 sdp 会查到错误结果或空结果。Skill 维护 `sdp_validator` 子模块在写命令前校验。

### 2.4.9 max_results 硬限制 ≤ 10

AnySearch 硬限制。Skill 默认 5，深度调研才用 10。

### 2.4.10 why 字段不可省

每条 query 必须有 `why` 字段，说明为什么选这个域。这是**可解释性**——上层 skill 调试和用户复盘都靠这个字段。

## 2.5 示例：对标博主全网足迹

```yaml
user_intent: "研究 <博主名>"   # 经过环 1 锁定
translation:
  intent_type: hybrid              # 博主名是专有名词 → Path B；但跨多平台 → 补 Path A
  keyword_strategy: proper_noun    # 直接用博主名（专有名词）
route:
  queries:
    - id: 1
      query: "<博主名> AI 观点"
      domain: "social_media"
      sub_domain: "social_media.social_media"
      sdp: "type=zhihu,keyword=<博主名>"
      keyword: "<博主名>"
      path: path_b
      max_results: 5
      why: "知乎同步发的深度文章，看技术观点"
    - id: 2
      query: "<博主名> 博客 播客"
      domain: "general"
      sub_domain: "general.general"
      keyword: "<博主名>"
      path: path_a
      max_results: 5
      why: "即刻动态 / 个人博客 / 播客 Show Notes"
    - id: 3
      query: "<博主名> AI 教程"
      domain: "social_media"
      sub_domain: "social_media.social_media"
      sdp: "type=wechatmp,keyword=<博主名>"
      keyword: "<博主名>"
      path: path_b
      max_results: 5
      why: "公众号文章，看长文体系"
  total_count: 3
  extract_targets:
    - "https://www.xiaoyuzhoufm.com/episode/...*"
  strategy: parallel
  fallback:
    - replace: id:3
      with: { domain: general, sdp: "keyword=<博主名> 微信公众号" }
```

## 2.6 升级影响隔离

AnySearch 升级改了 domain 名 / sdp key → 改 `domain_map.yaml` + `sdp_validator`。
上层 skill **零修改**。

这是 Skill 的核心封装价值。
