# 内容：故事怎么讲、场景怎么定、分镜怎么拆

## 1 内容类型与叙事骨架

| 类型 | 时长 | 骨架 |
|---|---|---|
| Logo 片头 | 4–10 秒 | 登场 → 一个亮点动作 → 定格收尾 |
| 情节短片 | 15–30 秒 | 目标 → 障碍 → 解决 → 落到品牌 |
| 喜剧小剧场 | 12–20 秒 | 目标 → 对峙 → 高潮 → 反转 → 反应 |
| 清单反转 | 12–20 秒 | 开场 → 数据逐条升级 → 最后一条反转 → 收尾 |
| 知识讲解 | 60 秒以上 | 钩子 → 问题 → 原理拆解 → 例子 → 总结，旁白驱动（尚无样例） |
| 口播 B-roll 与章节标题 | 跟随原片 | 跟着口播走，讲到哪配到哪；章节标题卡用二级标题原文（已有样片：教程视频的 Broll 与标题） |
| 歌词 MV | 跟随歌曲 | 按主歌、副歌分配视觉母题，剪辑点对节拍（尚无样例） |

样例《纸上出航》按情节短片骨架：画海（目标）→ 出航 → 页边悬崖（障碍）→ 画风飞越（解决）→ 落到便利贴"船长的角落"（品牌）。

《最后一块披萨》按喜剧小剧场：最后一块披萨（目标）→ 西部对决（对峙）→ 同时扑出、空中定格（高潮）→ 鸽子叼走（反转）→ 两人坐起来一起抬头看它（反应）。《一只猫的一天》按清单反转：睡 16 小时 → 盯墙 47 分钟 → 推杯子 3 次 → 凌晨跑酷 → 理你 0 次，开罐头翻成 ∞。

测试样例、展示用样片的题材要轻松有趣，不做工作类内容。

## 1.1 给口播视频配 Broll 与标题

1. 通读逐字稿，标出哪些段落画面已经有录屏（部署、点击、发提示词、真实案例），这些不配；只给概念讲解、比喻、流程、结论这类抽象段落配画面。
2. 列 Broll 清单：编号、对应的口播位置、一个主要动作、用什么做（纯代码还是加生图）。数量不设配额，宁少勿滥。每条 10 秒，无声，留出剪辑余量。
3. 标题：章节标题严格用逐字稿的二级标题原文，另有主标题；文字由用户拍板。每条 4 秒，带音效，读得出来的时间不晚于 2 秒。
4. 整期一个风格（以封面为准），一个场景，一个角色（同一套姿势），色板、字体、角色比例保持一致。
5. 每条先出关键帧拼图检查，再整片渲染；从最终 mp4 抽帧做质检，见 [checklist.md](checklist.md)。

风格和做法见 [styles/07_教程桌面舞台.md](styles/07_教程桌面舞台.md)。

## 2 场景设定

一个主场景，多个机位。只出一套分层场景，所有镜头在里面用虚拟摄像机取景，素材少，画面统一。好的主场景具备三样东西：能表演的平面（纸面），能制造冲突的边界（页边悬崖），能收尾的落点（便利贴）。

口播、教程类视频可以用"桌面舞台"：一张虚化的工作室背景加桌面，角色站在桌上，信息面板浮在半空，桌面留给字幕。

## 3 分镜拆解规则

骨架的每个节拍拆成 1 到 2 个镜头，每个镜头只讲一件事。时长分配：开场不超过 15%，冲突和高潮留足，结尾 2 到 3 秒落到品牌。一个动作之后给一个反应镜头（画完海回头看）。每个镜头写清景别、机位、时长、转场。有配乐时剪辑点最终对齐节拍（先按剧情排，配乐后再吸附拍点）。

角色单张停留超过半秒就要加生命感：定格节奏的小幅晃动、两张姿势交替、弹出符号（？！）、动作线。

喜剧节奏三拍：预备（蓄力、发抖）→ 夸张（扑出、速度线）→ 停顿（定格半秒，画面去色，只让反转的东西动）。反转后给一个反应镜头。笑点揭晓后至少停 1 秒。

## 4 产出链与分镜表格式

一句话情节 → 节拍表 → 分镜表 → 素材清单 → 场景文件 → 渲染。

分镜表每个镜头一张表：

| 项 | 内容 |
|---|---|
| 机位 | 景别、角度、镜头运动 |
| 画面 | 精确到 0.1 秒的画面节点 |
| 姿势排期 | 每段时间用哪张角色图 |
| 代码 | 这个镜头里代码负责的动效 |
| 声音 | 音效与音乐变化 |
| 素材 | 用到的素材编号 |

完整样例见 `examples/` 里的各个 `scene.py`，以及 [styles/](styles/00_风格索引.md) 里每张风格卡。
