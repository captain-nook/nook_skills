# 风格卡：水墨 / 水彩（已验证）

样例：《一叶行舟》v2，水墨水彩；素材由千问出图，样例工程不随库提供。

| 字段 | 内容 |
|---|---|
| 画面材质 | 温润生宣纸纹理（象牙暖白底色、植物纤维交错、吸水棉絮斑驳）；画面呈现中式写意水墨，墨分五色（焦、浓、重、淡、清），留白意境 |
| 技术档位 | 代码 + 生图（Qwen Image 2.1 加速通道出透明底水墨素材，`wash` 模块做宣纸与水墨晕染特效） |
| 帧率节奏 | 镜头与水波 24fps 流畅平滑，水墨扩散慢速渗透，小船 24fps 破浪行进，节奏舒缓富有禅意留白 |
| 构图 | 先定水平线：山只在线以上，山脚渐隐入云雾；线以下是留白江面，只散几笔短断水纹。中景山成组放，组间留白。主体小（船宽约画面 1/5） |
| 运动方式 | 长卷横移（远山视差 0.22、中景 0.5、水纹按深度 0.55–1.3、主体 1.0、近景孤松 1.35）；主体在画面里另有路径，不跟镜头同速 |
| 转场 | 横向长卷推轨展开（不硬切，全片在一张连续水墨长卷中自然延展）；结尾竖排题款 + 代码刻的白文印 |
| 典型特效 | 墨滴晕开（焦墨芯 + 淡墨晕 + 水渍深边）后山水从墨迹处渗出、一笔擦出主体、短断水纹与船尾尾迹、绕水线翻转的波动倒影、竖排题款逐字洇出、白文印 |
| 适合内容 | 中式叙事、文化内容、品牌心智与格调表达、哲理金句短片 |

## 出图提示词基准句

```text
The image features a [element] in traditional Chinese ink wash painting style, sumi-e xieyi brushwork, layered black and grey ink wash tones with delicate translucent wash, elegant negative space, minimalistic and tranquil landscape, high quality calligraphic art.
```
注：生成透明底素材需带 `"alpha": true`，模型会自动将背景置为透明通道。

## 代码参数

- 宣纸底色：温润生宣 BGR (230, 240, 246)，长纤维高斯模糊核 (0.9, 8.0)，横纤维 (7.0, 0.8)。
- 墨水混合：必须采用正片叠底（Multiply），将素材 RGB 与纸张底纹相乘，使纸张微纤维从淡墨与留白处自然透出。
- 墨滴晕染：边缘用 2–8 阶随机角向起伏加纤维噪声（不要用少数几阶正弦，会出对称星形）；焦墨芯、由内向外变淡的淡墨晕、晕边一圈水渍深边。
- 印章：代码用隶书刻白文，印面与边线加噪声剥蚀，正片叠底到纸上；盖印只做 0.12 秒压下，不做弹跳。

## 已验证的坑

1. **不可直接贴图覆写**：水墨画如果直接做 Alpha 覆盖（Over），会像贴了一张不透明贴纸，切断纸张纤维纹理。必须走正片叠底水墨混合模式（`blend_ink_sprite`）。
2. **长卷图视差对齐**：远景水墨山峦透明底素材在长卷横移时，视差系数建议设为 0.25~0.3，速度太快会破坏水墨画的静谧深远感。
3. **倒影翻转轴**：倒影要绕素材上的水线翻转，v1 绕素材原点翻，倒影跑到了人物头顶。
4. **印章文字**：出图模型刻不出指定汉字，印章必须代码生成。
5. **OpenCV Windows 中文路径**：保存与读取包含中文路径的文件必须使用 `nookanim.assets.imread` 和 `imwrite`（底层使用 `imdecode` 与 `imencode`）。
