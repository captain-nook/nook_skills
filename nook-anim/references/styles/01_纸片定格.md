# 风格卡：纸片定格（已验证）

样例：《纸上出航》，纸片定格；素材由千问出图，样例工程不随库提供。

| 字段 | 内容 |
|---|---|
| 画面材质 | 写实微距桌面 + 纸片剪纸角色；角色外轮廓一圈白纸边，加离地投影后像立起来的剪纸 |
| 技术档位 | 代码 + 生图（Qwen Image 2.1 加速通道） |
| 帧率节奏 | 角色、船等实物 12fps 定格，每张停两格；墨线、浪、镜头 24fps，两种节奏形成反差 |
| 运动方式 | 关键姿势由图生图编辑；身体起伏、倾斜、挤压、位移由代码补；停留超过半秒加晃动或两张交替 |
| 转场 | 硬切为主；全片共用一套分层场景，由虚拟摄像机换机位 |
| 典型特效 | 马克笔墨线逐笔画出、墨水海、水花墨滴、瀑布、漩涡风线、速度线、手写字、星光、弹出问号 |
| 适合内容 | 情节短片、品牌故事、Logo 收尾 |
| 场景素材 | 宽幅场景图（2K，约 3072×1280）一张，镜头都在里面取景；道具单独透明图，放进场景坐标 |

## 出图基准句

角色：paper cut-out cartoon character, flat hand-drawn illustration with watercolor and colored pencil texture, clean dark outlines, a thin white paper border around the whole silhouette like a sticker cut out from paper.

场景与实物道具：realistic macro photography, warm golden side light, shallow depth of field。白色道具写 opaque cardstock，每条边缘有 rim highlight。

## 代码参数

墨水色品牌蓝 #1E5BD8，正片叠底；马克笔线宽 5–7（平面坐标），两头收细，纹理固定在平面坐标。接触阴影强度 0.35–0.4。胶片颗粒 0.01，暗角 0.25。

## 已验证的坑

人船分层拼接会穿模 → 人船组合素材。道具做成屏幕层会悬空、透视不对 → 放进场景坐标。旗子方向要朝运动反方向。飞行弧线和近景取景要给旗杆留头顶空间。画画时人物以笔尖为锚点跟着笔画走。
