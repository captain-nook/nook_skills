# 风格卡：扁平动态图形 MG（已验证）

样例：《一只猫的一天》，样例工程 `examples/06_cat_day/`。

| 字段 | 内容 |
|---|---|
| 画面材质 | 纯色底 + 几何图形（圆、三角、圆角矩形）拼出的角色和图标，无描边；每段一种底色 |
| 技术档位 | 纯代码，不出图（`mg` 模块） |
| 帧率节奏 | 24fps；时间轴按拍写（`mg.Beat`），120 BPM 下一拍 0.5 秒，每拍至少一个元素变化 |
| 运动方式 | 弹入（ease_back 过冲）、弹簧、数字滚动（缓出，前快后慢）、砸入（从 3 倍缩到 1） |
| 转场 | 圆形擦除（提前半拍开始，切点落在拍上）；情绪反差段用白闪硬切 |
| 典型特效 | 弧形进度环、计数器、残影、翻牌（纵向压扁再展开）、弹出文字 |
| 适合内容 | 数据、清单、产品要点、反差梗 |

## 版式

统一版式比每段花样更重要：左边图形、右边"标签 → 大数字 → 单位"，三者依次隔半拍弹出。数字 300 号字，标签 64，单位 72，补充说明 44。

## 配乐

代码合成的鼓 + 贝斯 + 拨弦，和画面共用同一个 `Beat`，天然对拍。反差段用配乐制造：夜里只留贝斯和踩镲；笑点前一拍整段急停（唱片刹车音），揭晓时一起回来。

## 已验证的坑

1. 角色颜色不能和某段底色相同（橙猫放在橙底上就消失了）。先定角色色，再给各段选底色。
2. 笑点揭晓后至少留 1 秒再转场，否则会被下一段的擦除盖掉。转场提前半拍开始，这半拍也要算进笑点的停留时间里。
