# 风格卡：火柴人 / 极简角色（已验证）

样例：《最后一块披萨》，样例工程 `examples/05_last_pizza/`。

| 字段 | 内容 |
|---|---|
| 画面材质 | 暖白底 + 黑色粗线火柴人（线宽 11，圆头白底），道具扁平上色、黑描边；情绪段落整体换底色（西部夕阳） |
| 技术档位 | 纯代码，不出图（`stick` 模块） |
| 帧率节奏 | 24fps 流畅；喜剧三拍：预备（蓄力发抖）→ 夸张（扑出、速度线）→ 停顿（空中定格 0.5 秒，画面去色） |
| 运动方式 | 骨骼姿势关键帧插值 + 走路循环 + 两段反向动力学（手伸向目标）；两个角色用镜像 + 一点时间差，不完全对称 |
| 转场 | 硬切为主：全景 ↔ 大特写（眼睛、手指），切点就是笑点的节拍 |
| 典型特效 | 弹出符号（！嗝）、晕眩星、撞击放射线、速度线、飞走的帽子、风滚草、上下电影黑边 |
| 适合内容 | 段子、反转小剧场、流程演示 |

## 代码参数

骨长：头半径 38、脖子 14、躯干 130、上臂 64、前臂 58、大腿 72、小腿 70。角度一律绝对角（四肢 0 = 竖直向下，正值朝面朝方向；躯干 0 = 竖直向上）。站立、走路、蹲下时把最低的脚贴到地面（grounded），腾空段直接给胯的轨迹。画在 uint8 画布上（cv2 抗锯齿只对 8 位图生效），镜头 `stick.Cam` 同步缩放线宽，特写直接放大 4 倍取景。

## 角色区分

极简角色靠一个小标记区分：A 头顶一个小卷，B 头顶三根翘毛。表情只用眼睛（点、圆、眯、X、螺旋）、眉毛（生气）和嘴（平、笑、O）。

## 已验证的坑

1. 帽子这类头部配件要按头的朝向放，不能按躯干方向放：身体扑平时头是抬着的，按躯干放会把帽子扣到脸上。
2. 空中定格时两人要留出距离，定格结束后再冲一下才撞上，撞头才有力度。
3. 撞击后的姿势插值要经过"后仰翻转"（躯干角度跨过 0 到负值），直接插到躺平会像站在桌上。
