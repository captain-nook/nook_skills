# 风格卡：教程桌面舞台（扩展，已验证）

样例：教程视频《Opus 5.5 动效视频 nook-anim skill 教程》的 8 条 Broll 和 8 条标题，共用件在 `examples/tutorial_kit/`。

| 字段 | 内容 |
|---|---|
| 画面材质 | 千问出的一张"虚化深蓝工作室 + 胡桃木桌面"背景，整期共用；信息面板是深蓝玻璃卡片（青蓝描边、外发光）浮在半空；Q 版角色带白色贴纸描边站在桌面上 |
| 技术档位 | 代码 + 生图：背景 1 张、角色姿势若干、标题字每条 1 张（千问）；其余全部代码 |
| 帧率节奏 | 24fps 全流畅；走路用两帧交替 + 起伏 + 轻摇；信息面板弹入带过冲 |
| 运动方式 | 角色在桌面走、蹦上台阶、跟着流程走；面板弹入、内容逐层长出；标题字砸下、压扁回弹、波浪逐字起跳、扫光 |
| 转场 | 无。每条是独立的短片段，由剪辑决定怎么接；每条首尾各有淡入淡出 |
| 典型特效 | 冲击环、星光、彩纸、扫光、震屏、放射光芒、代码碎片飞行、吸附冲击波 |
| 适合内容 | 口播、教程、科普类视频的 Broll 和章节标题卡 |

## 色板与版式

深蓝底 `#0A1330 → #1A3373`；卡片 `#22397D → #142655`，描边 `#6A93FF`；霓虹渐变青 `#35D0FF`、蓝 `#4C7DFF`、紫 `#9A5CFF`、粉 `#FF5FA8`；强调黄 `#FFC83D`、橙 `#FF8A1F`；正向绿 `#3DDC84`。文字白色，深色描边。

画面上三分之二放信息面板，下三分之一是桌面和角色，桌面留给字幕。桌面背景整张往下挪 130 像素（顶部用虚化补），让桌面变成底部的台面。角色脚底线在 y=968。

## 标题字

千问出透明底"纯文字 PNG"，封面同款：亮青到近白淡紫到柔粉的高调渐变、白色高光、深蓝描边、深蓝立体厚度、霓虹光晕、短放射线。提示词骨架见 [../image-gen.md](../image-gen.md) 第 5 节。代码把字裁边、斜 13%（封面是斜体）、按 4 秒时间线做动效并合成音效：

| 时间 | 动作 |
|---|---|
| 0.18–0.62 秒 | 从上方砸下来，下落时拉长、斜着 |
| 0.62 秒 | 落地压扁 → 弹簧回弹；震屏；冲击环；星光和彩纸炸开 |
| 0.67–1.05 秒 | 一道波浪从左到右滚过字（每列按位置延迟起跳，字形不切开） |
| 1.05–1.6 秒 | 一道光扫过；同时画出橙黄下划线 |
| 0.55–1.1 秒 | 角色从画面下方跳上来，落地压扁，然后呼吸 |

音效：入场风声、下落声、撞击低频加弹跳声、逐字木琴音（音高随字数上行）、光扫声、亮晶晶的三连铃、角色跳出声。前两秒有声，后两秒留白。

## 代码分层

`common.py`（色板、桌面舞台、玻璃卡片、图标、角色与走路）、`bkit.py`（Broll 的小部件：球、迷你画布、代码窗口、播放窗口）、`titlekit.py`（标题动效与音效），每条片子只有一个短场景文件。这些共用件放在项目工程目录里，场景文件直接 `from common import *`（引擎加载场景时会把场景所在目录放进 `sys.path`）。

## 已验证的坑

1. 标题字的色彩描述写"蓝到紫到洋红"，出来是深紫暗沉的字；要写"明亮、通透、高调的青到淡紫到柔粉"。
2. 角色站在带字的卡片下面，头会挡住数字和文字。让角色停在卡片外侧的空地，或者给标题让出高度。
3. 面板整个在画面上沿之外、只有阴影边距落在画面里时，渐变切片会出错（已在 `common.panel` 里补了边界保护）。
4. 画面片段"吸附到拍点"的演示，每块要正好占整数拍，吸完首尾相接；否则吸附后互相叠在一起。
5. 无加速 LoRA 的千问通道，官方值是 25 步、CFG 1，不要按老习惯设 CFG 4。
6. 同一个目录里不要并行渲染两条片子，进度文件会互相占用（引擎已容错）。
