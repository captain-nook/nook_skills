# 风格卡：手绘线稿（已验证）

样例：《画个方向》，样例工程 `examples/02_draw_direction/`。

| 字段 | 内容 |
|---|---|
| 画面材质 | 暖白纸纹上的黑色墨线，点缀一两种品牌色（路与箭头品牌蓝、边界与灯光品牌黄）；纸放在木桌上，拉远时看得到纸边 |
| 技术档位 | 纯代码，不出图（`sketch` 模块生成纸纹） |
| 帧率节奏 | 线条 8fps 重抖（boil），角色 12fps 定格，镜头 24fps |
| 运动方式 | 角色由代码骨骼驱动（关节角度、步态相位），开场可逐笔画出角色；物件按笔画顺序逐笔出现 |
| 转场 | 一张长卷纸上连续平移取景；结尾拉远看全程 |
| 典型特效 | 逐笔画出、抖动线、弹出符号（？！♪）、晕眩星、光束、手写字 |
| 适合内容 | 情节短片、知识讲解、口播 B-roll、观点表达 |

## 代码参数

墨线宽 2.2–3.4（场景像素），路和箭头 8–9；抖动幅度 2.0，重采样间距 6。纸色 BGR (235, 241, 246)。角色合成三层：纸白遮挡 → 彩色填充 → 黑色轮廓，身后的线不会透过来。颗粒 0.008，暗角 0.18。

## 已验证的坑

符号字体要确认有这个字（雅黑没有"♪"，用 Segoe UI Symbol）。中文手写字体里的英文字母难认，混排时英文单独用英文手写体。两个角色互动时注意中间有没有物件挡着（击掌不能隔着灯塔）。
