# 0 这张单子解决什么

在此之前 nook-topic 只有方法论、没有输出契约，所以"跑一次选题"的产物是**一堆材料**而不是**一张单子**。
材料需要人再读一遍才能用，那机器就没省下判断成本。

**判据：一张合格的选题单，人扫一眼就能拍板做哪个，不需要回头翻原始数据。**

# 1 生成流程（三段，缺一不可）

```text
① 脚本采   你自己的采集脚本 --direction "方向词" --en "English query"
             多源齐跑 → 落同一轮次样本文件 → 输出材料摘要
② AI 判    读摘要，按 §2 四步做语义判断（写不成 if-else，必须 AI 做）
③ 人定     从 2-3 个候选里选一个，AI 不拍板
```

# 2 AI 判断四步（顺序不可乱）

1. **受众关（硬门，先过）**：这一簇的受众是不是「靠内容吃饭、痛点是产能低和不知道发什么」的人？
   **不是就砍，信号再强也砍。**（260726 教训：五源共识齐刷刷指错方向，因为采集通道采的是 AI 博主生态，
   而 AI 博主的受众是 AI 爱好者，不是自媒体工作者/超级个体。**信号强 ≠ 受众要**。）
2. **噪声剔除**：播粉比/中位比是**发现器不是判断器**。极小号 + 单条病毒式猎奇会把比值顶上天
   （实测 362 粉 50 万播放 = 1392x，内容是搞笑猎奇）。粉丝地板已在脚本里，**语义噪声（猎奇/擦边/
   无关娱乐）在这一步由 AI 剔**——不硬编词表，否则每出一种新噪声就要改代码。
3. **语义聚类**：不同措辞的同一母题并簇。**关键词永远漏**（「用 Codex 写公众号」搜不到「AI 写作」），
   靠读标题判断，不靠穷举。
4. **找空隙**：现有内容都在讲什么角度？**没人讲的是什么？** 差异化在这里，不在热度里。

# 3 选题单模板

```markdown
# 选题单 · {方向} · {日期}

## 一、本轮材料
- 采集轮次：[[{日期}_{轮次}_采集轮次]]（{N} 批次 / {M} 条）
- 通道：见你自己的采集契约（示例：B站低粉爆款 / YouTube低粉爆款 / 信号雷达 / 长文收藏库 / 新闻雷达）

## 二、受众关筛查（先砍后议）
| 簇 | 受众是否命中 | 处置 |
|---|---|---|
| {簇名} | ✅/❌ 理由 | 保留 / 砍 |

## 三、供给格局（这个方向现在长什么样）
- **已被讲烂的角度**：{列举，附证据条目}
- **有人讲但没讲透**：{列举}
- **没人讲的空隙**：{列举 ← 差异化在这}
- **反面证据**：{做了但扑街的角度，附数据 ← 最值钱，防踩坑}

## 四、候选（2-3 个，不拍板）
### 候选 1：{一句话}
- 受众：{哪一层，痛点是什么}
- 需求证据：{具体账号+具体数字，可自查}
- 差异化：{空隙在哪}
- 证据支撑：{我手上有什么} / **一周内能否做出来：能/不能**
- 人设一致：**以什么身份讲**（⚠️ 无结果背书时，不得用承诺型框架）
- 时机：{有/无窗口}
- 风险：{}

## 五、待人定
{把选择权交回，列出关键取舍}
```

# 4 硬规则

- **AI 不拍板**：输出 2-3 个候选，最终选择权在人（全流程只有「选题对齐」这一个强制人工确认点）。
- **数字必须可自查**：报具体账号名 + 具体数字。编不出就不用数字。
- **身份关不可跳过**：候选的第 5 项「人设一致」要回答**以什么身份讲**。
  真实踩坑案例：账号处于探索期、无涨粉结果，却出了「低粉打赢大号」这种**承诺型**题面
  （潜台词=我会打赢所以我能教你），当场被否。
  **如果你的账号还没有结果背书，成功模式应该是「我做出来了，模板给你」——背书来自做出来的东西，不是结果数据。**
  这条规则要接到你自己的写作/审校 skill 里，确保标题和钩子不越过账号当前的可信度。
- **反面证据要单列**：做了但扑街的角度比爆款更防坑（真实踩坑：替受众读内容的频道播放个位数
  → 推出「要教人拥有系统，不能替人当简报」）。
