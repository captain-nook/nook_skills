# 选题的判断与角度（选题的灵魂）

选题是整条内容链的源头,也是最难的一环。一步错,后面写作再好、视觉再美,都是把没人看的东西做得精致。本文件讲选题真正难的部分——**从信号到选题的判断**,和**差异化角度的手艺**。公式和格式在 SKILL.md,那些是骨架,这里是灵魂。

## 一、先纠正认知:选题是预测,不是分析

- 分析历史很容易(哪些火过),但**火过的不一定再火**(时效、审美疲劳、已被做烂)。选题本质是**预测**"这个题在未来会不会涨粉",预测天然不确定。
- 所以目标不是"选出必爆的题"(不可能),而是三件可做到的事:**提高命中率**(筛掉低质题)、**控制风险**(常青打底+热点博弹性)、**快迭代**(靠量和反馈优化,不靠单次精准)。
- 抱着"选出必爆题"的心态会瘫痪;抱着"提高命中率的概率游戏"心态才能持续产出。

## 二、信号 ≠ 选题:中间隔着"判断"

采集给的是**信号**(热点、爆款、评论),不是选题。信号到选题之间有一道鸿沟,靠判断跨过去。**平庸的人把信号抄一遍(跟做爆款=同质化=淹没),高手从同一信号提炼出一个差异化角度。** 这道判断是选题的核心能力,也是最难自动化的。

不要把"这个题火"当成"我要做这个题"。火的是**别人的答案**,你要找的是**还没被满足的需求**或**你能给出的不同答案**。

## 三、从信号到选题的五关(一个题要全过)

每个候选题过这五关,大部分信号会在第 2、3 关死掉,这是正常的、健康的筛选:

1. **需求验证**:这个题有真实需求吗?——不是"我觉得有用",是市场/评论区证明有人要。最强的需求信号不是"什么内容火"(那是已被满足的),而是**评论区反复在问、搜索在搜、但还没好答案的问题**(见第四节)。
2. **供给独特**(最关键一关):我能做出和现有内容不一样的角度吗?——市场有需求但已被做烂的题,不如没做的。同质化=淹没。过不了这关的题直接砍。差异化怎么找见第五节。
3. **证据支撑**:我有真实的证据/经历/结果做这个题吗?——创作者的护城河是"亲自下场"。没有真实证据的题=手册/空谈,写出来必然平庸(公众号首篇失败就死在这:拿框架转述,没有亲历证据)。**没证据的题,要么去拿到证据,要么放弃,不硬写。**
4. **人设一致**:这个题符合"人定方向AI执行"的创作者吗?——不是所有热点都能做。AI换脸火,创作者也不做。选题的边界由人设(见你自己的账号人设文档（本仓库未附带）)划定,尤其"思想钢印"这条主张能不能自然扣上。
5. **时机**:现在做是不是正好?——新工具窗口期、热点未过期、还没被做烂。

一个题五关全过,是好选题。只过一两关的,砍掉或搁置。

## 四、被忽略的最强信号:评论区需求

大多数人盯着"什么内容火",但火的内容是**别人已经给出的答案**,你再做就是同质化。真正的蓝海在**评论区**:

- 爆款视频/笔记的评论区里,反复出现的**提问、异议、"求教程"、"这个怎么做"**——这些是市场明确表达、但还没被好好满足的需求。
- 你搜一个关键词,如果**搜索结果都不满意**(标题党、内容空、没讲透),这个题就是机会。
- 评论区需求的价值:①明确(观众自己说的)②未被满足(所以他们还在问)③自带钩子(直接回答一个真问题最抓人)④可复用(一个问题一批人有)。

**这个源不需要大规模爬取**——人工刷几个对标账号的爆款评论区就能拿到,尤其在小红书采集受限时,这是更可靠的需求来源。

## 五、差异化角度:选题真正的手艺和护城河

市场有需求的题,大家都在做。**赢在角度,不在题目。** 同一个"AI做PPT",可以是教程、避坑、反差(居然能改)、观点(别再抽卡了)、结果(我三天做完一个月的活)——角度决定生死。找差异化角度的几种手法:

- **反主流**:大家都说 A,你说"其实不是 A"(认知反差型,点赞最高)。"大家骂AI垃圾内容,我觉得骂错了对象。"
- **换视角**:大家从工具讲,你从人/焦虑/身份讲。"AI真正淘汰的不是程序员。"
- **降维**:大家讲高级用法,你讲"零基础也能懂"(保姆级,创作者招牌)。
- **亲历**(创作者最强护城河):大家讲理论,你讲"我真做了,踩了这些坑,跑通了"。真实证据是别人抄不走的差异化。
- **组合升维**:把两个不相关的东西连起来(信息采集→北京折叠)。

**创作者的选题护城河 = 亲自下场的真实证据 × "人定方向AI执行"的观点框架。** 选题时优先选那些**能发挥这个护城河**的题——有你真实项目/经历撑腰、且能扣到"给AI立边界"主张的题,别人抄不了,也最像你。

## 六、证据先行:选题跟着证据走,不是选了题硬凑证据

一个反直觉但关键的顺序:**先盘点你手里有什么真实证据/项目/经历,再从证据出发找选题**,而不是先定个热门题再去硬凑证据。后者必然写成空谈/手册。

每次选题前先问:我最近真实做了什么、跑通了什么、踩了什么坑、有什么可展示的结果?这些是你的"选题弹药库"。热点信号负责告诉你"哪个弹药现在该打",但弹药本身来自你的真实积累。

无证据的纯热点题,每周最多 1-2 个,且必须有独到判断,否则就是新闻搬运。

## 七、选一批的约束(矩阵级判断)

选题很少是选一个,而是选一批(周更/矩阵)。批量判断加几条:

- **常青 × 热点配比**:常青题(需求持续、可复用、能反复做)打底求稳,热点题(时效、博弹性)点缀求爆发。不要一批全押热点(过期就废),也不要全常青(没爆发力)。
- **母题多样性**:一批题覆盖多个母题,避免审美疲劳。同一母题一周内不同平台可做不同角度,但不重复钩子。
- **平台适配**:同一母题在抖音/小红书/视频号/公众号做完全不同的角度和形式(见各线 content-design)。
- **产能诚实**:证据够几条就报几条,不为凑数量注水。数量是结果不是目标。

## 八、选题是概率游戏:靠迭代,不靠单次精准

- 选题好坏要发布后数据才知道,且受封面/时段/算法干扰,单次很难精准归因。所以**别指望一次选准,要靠量和反馈迭代**。
- 每个选题记录"**预测理由**"(为什么我觉得它会火)和"**实际数据**",发布后对照。积累多了,你会形成"什么题在我这儿火"的**私有认知**——这是别人没有的、越用越准的选题直觉。
- 上周复盘的 keep/kill 直接作为下周选题的先验:火过的母题/角度延续,扑街的降权。

## 十、选题的三个源(角色不同,别只盯热点)

选题不是采一堆热点。之前的采集偏废了——太重热点(news/bili),轻了深度和证据。三个源角色分工,缺一不可:

1. **证据源 = 中视频 10+ 期**(已跑通的成果 + 可复用 Broll)。回答"我讲什么有底气"。这是创作者选题**最大的护城河**——证据现成,"证据支撑"这关直接赢,别人抄不走。
2. **深度源 = Supabase 采集库**(X + 公众号长文,己方数据可直接访问)。回答"往深里挖什么议题、和谁的观点碰撞"。热点给不了深度,长文库给。用法:聚类看哪些议题反复出现=行业在深度讨论什么;给创作者的观点提供佐证或反驳对象(卡兹克式找论据/反论据)。
3. **时机源 = RSS / news 热点聚合**(ai-news-radar 等)。回答"现在什么在发生、什么时候蹭"。只是时机,不是选题本身。

偏废任何一个都不行:只有热点=肤浅追风;只有证据=闭门造车不合时;只有深度=自嗨无时机。**"采集啥"的答案不是采更多热点,是三源交汇 + 再过呈现/受众/人设三关。**

## 十一、选题的基本单元是"价值点",不是"一条内容"(核心结构)

关键认知升级:选定的不是"一条抖音",而是一个**价值点**;一个价值点跨平台**裂变**成 N 条不同选题。

例——价值点"AI 做的 PPT 能随便改(因为给 AI 立了边界)":
| 平台 | 裂变角度 |
|---|---|
| 抖音 | 痛点情绪反差:"你还在加班改 PPT?" |
| 小红书 | 搜索收藏:"AI 做可编辑 PPT 的完整清单" |
| 视频号 | 业务转发:"帮团队每周省下做 PPT 的时间" |
| 公众号 | 观点深度:"AI 做 PPT 总翻车,因为没有边界" |
| 中视频 | 完整教程(本体/证据源) |

好处:①一次选题裂变多条,效率倍增 ②天然多平台协同 ③价值点来自证据(中视频),证据先行自动满足 ④同一价值点不同平台不同角度,**不算重复**。

**选题流程升级**:先选价值点(从证据源 × 深度源 × 时机源的交汇里选)→ 再按平台裂变角度(各平台 content-design 定角度)。

## 十二、中视频价值点矿(证据先行的最强实现,建议一次性盘点)

10+ 期中视频每期 = 一套跑通的成果,里面藏着多个可独立成篇的价值点(一个痛点/一个反差/一个技巧/一个坑/一个观点)。建议一次性盘成"价值点矿",长期复用:

- 每期拆出 3-5 个价值点。
- 每个价值点标:**母题 / 可复用 Broll / 适合哪些平台 / 是否已被短内容化**。
- 用途:选题时从矿里挑还没裂变的价值点,配当周热点时机,直接出跨平台选题。拍摄成本极低(Broll 现成)。
- **关键约束(用户强调):避免同母题反复讲。** 矿按母题聚类,识别哪些是真不同母题,轮换着来,不把一期反复榨、不让不同期其实讲同一母题。

这把"证据先行"从口号变成一个可查的资产库,是创作者选题效率和质量的地基。

## 十三、痛点三步公式与 agent 指令纪律（260721 补，治"隔靴搔痒"）

**选题总打不动人的病根**：从"技术解决方案"出发想选题（有个技术点"去 AI 味"→做《去 AI 味的 5 个方法》），而不是从"用户的具体糟糕处境"出发（AI 稿被甲方一眼识破全部返工/口播稿念着别扭完播上不去）。

**三步公式**：`具体场景 + 无效共识 + 反常识解法`

1. **具体场景**：技术名词翻译成真实场景+糟糕结果（已由患者句 4 具体覆盖）。
2. **无效共识**（新增的关键一环）：先说出用户普遍试过但没用的方法，接住他的失望——"删了综上所述、改了首先其次，甲方还是一眼看出来"。用户不是不知道那些方法，是试过了不管用；不立这一环，他的第一反应就是"又是这一套"。
3. **反常识解法**：跳出表层技巧给底层答案（创作者护城河：别人教改词，我讲"为什么改词没用"）。

**agent 指令纪律（Step 2 硬规则）**：禁止"基于 XX 技术点想选题"这种指令。正确顺序：先让 agent 拆"目标用户在该场景最头疼的 3 个具体麻烦 + 他们试过但没用的方法"，再基于困境出选题。先找痛，再给方法。

## 九、当前现实约束:小红书采集受限(2026-07)

小红书风控已对自动化采集发出警告。选题的数据源策略相应调整:

- **降低对小红书原生大规模采集的依赖。** 好在选题的核心(需求验证、差异化角度、证据先行)本来就不靠大规模爬取。
- 小红书需求信号改用**低强度人工**:自己刷对标账号、看爆款评论区、看公开榜单,手动记几条。不跑自动化爬取。
- 更倚重两个不需要爬取的源:**评论区需求**(人工观察)和**你自己的证据**(选题弹药库)。
- 其他平台(B站/新闻/公开数据)交叉验证需求,不依赖单一平台。
