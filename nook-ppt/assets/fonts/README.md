# 字体

**字体文件不随库提供，请自行下载安装**（都可以免费使用；各自的许可以官方页面为准）：

| 字体 | 用在哪些风格 | 下载 |
|---|---|---|
| 思源宋体（Source Han Serif CN）中等、特粗 | 船长课堂、刊物·图纸、东方雅集、纸片手作（标题） | https://github.com/adobe-fonts/source-han-serif （SIL OFL） |
| 霞鹜文楷（LXGW WenKai）Light | 纸片手作（正文）、船长课堂（手写批注） | https://github.com/lxgw/LxgwWenKai （SIL OFL） |
| MiSans（常规、Semibold） | 发布会·暗场 | https://hyperos.mi.com/font （官方使用许可） |

安装：Windows 上选中字体文件，右键"为所有用户安装"（PowerPoint 需要装进系统才能显示）。

**量字用的字体文件**：主题依次查找环境变量 `NOOKPPT_FONT_DIR`、当前用户字体目录、系统字体目录、本文件夹。文件名需要和下面一致（下载后重命名，或把文件放到本文件夹）：

- `SourceHanSerifCN-Medium-6.otf`、`SourceHanSerifCN-Heavy-4.otf`
- `LXGWWenKai-Light.ttf`
- `MiSans.ttf`、`MiSans Semibold.ttf`

**没装也能用**：缺哪个字体，主题就自动退回系统自带的微软雅黑，量字和显示保持一致，版式不会坏，只是字形不同。
