# 素材库（透明底 PNG）

可复用的图标、船长姿势和装饰。用法：

```python
deck.corner_icon(s, 卡片矩形, "assets/library/icons_ink/bulb_灯泡.png", size=64)   # 卡片角标
deck.sticker(s, "assets/library/captain_poses/think_思考.png", 中心x, 脚底y, 高度)   # 自由摆放
```

| 文件夹 | 内容 | 配合的风格 |
|---|---|---|
| `icons_ink` | 墨线描边图标 10 个：采集盒、灯泡、靶、纸笔、质检文件、素材文件、手机、废稿纸笔、放大镜、纸飞机 | 船长课堂 |
| `icons_blue` | 淡蓝手绘图标 5 个：收纳盒、灯泡、靶、纸笔、对勾文件（较淡，深色底不明显） | 备选 |
| `editorial_icons` | 「刊物·图纸」线稿图标 18 个：笔记本、文件夹、钥匙、聊天、大模型、Agent、.md 文件、权限盾、停止手、扳手、计划、备份、撤销、清单、按量计费、报错、路标、地球（深色底上要衬浅色底板） | 刊物·图纸 |
| `captain_poses` | Q 版船长全身姿势 9 个：抱臂、指、介绍、摊手、思考、走（两帧）、惊讶、V 手势 | 船长课堂、明亮扁平、纸片手作 |
| `deco` | 星光、彩纸屑、Logo（四色块、船长帽） | 深色底装饰 |

船长提示表情 15 张在 `../styles/captain-class/tips/`。

**来源与许可**：这些图由作者用千问 Image 2.1 生成。船长是作者原创角色，约定见仓库 `README.md` 的"素材库与船长 IP"。**你可以自己重新生成或替换**：每个风格包的 `prompts.md` 有提示词骨架，`jobs_*.json` 有出图任务；本机能跑 ComfyUI 或有别的出图 API 就行，按同名 PNG 放回即可，不依赖这里的图。
