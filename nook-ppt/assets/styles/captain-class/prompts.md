# 船长课堂：视觉与提示词

- 气质：方格笔记本加纸片卡片加船长贴纸，明亮、手作；墨线描边加硬投影，标题下压马克笔高亮。
- 人物：Q 版船长（作者的个人形象）。15 个提示表情在 `tips/`（`TIPS` 字典已按"注意、想一想、有窍门、反常识……"配好标签），姿势图在 `assets/library/captain_poses/`。**发布本 skill 时是否带船长形象由作者决定**；不带时可以把 `tip()` 换成普通提示卡。
- 配图规则：船长的表情要和这一页的意思对应（想一想=定位，有窍门=方法，做得好=收尾），不要随便挑。
- 底图：`paper_bg.png` 暖白纸张加淡蓝方格；`talk_bg.png` 是口播场景底（可选）。颜色：橙 F26B21 是品牌强调，小字不要用它（对比度不够），用深橙 B8450A。
- 没有出图任务：表情图来自视频抽帧加白色贴纸描边，不是千问出图。
