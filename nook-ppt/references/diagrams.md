# 图示：内容是什么结构，就画成什么图

PPT 是视觉。内容本身有结构时，要画成对应的图，**不要全部排成一排卡片**。261002 复核样片时发现：费曼学习法的"四步循环"被排成四张卡片，一整批样片里几乎没有循环、阵列、金字塔。从此提纲阶段每一页都要先选"图示类型"，再选风格。

## 1 内容结构 → 图示（零件）

| 内容的结构 | 图示 | 零件 | 动效顺序 |
|---|---|---|---|
| 首尾相接、反复进行（步骤闭环、增长飞轮、复盘周期） | 循环图 | `cycle_ring()` | 环先擦出，节点和箭头沿顺时针依次出现 |
| 层级、基础与上层（收入结构、优先级、保护顺序） | 金字塔 | `pyramid()` | 自下而上（先出基础） |
| 一层层筛选、转化、流失（获客、选题筛选） | 漏斗 | `funnel()` | 自上而下 |
| 两个维度交叉的分类（重要×紧急） | 带坐标轴的矩阵 | `matrix(x_axis=, y_axis=, col_labels=, row_labels=)` | 逐格出现 |
| 一组并列的同类项（周历、清单、选题卡、反馈分类） | 阵列 | `array_grid()` | 逐格出现 |
| 两个或三个概念有重叠（分工、搭配、构成要素） | 韦恩图 | `venn()` | 圆依次出现，最后出交集 |
| 整体的构成比例（时间预算） | 环形图（原生图表，带数据） | `donut()` | 擦出 |
| 先后顺序、流程 | 箭头流程 | `chevrons()` / `flow()` | 沿方向 |
| 随时间的数据 | 折线图 / 柱状图 | `linechart()` / `chart()` | 擦出 |
| 对照 | 左右对比 | `compare()`（deckkit）/ 两张卡 | 左右 |
| 重点大数字 | 大数字卡 | `stat_row()`（deckkit） | 逐个放大 |

零件都是原生形状或原生图表，字、数据在 PowerPoint 里可改；颜色、描边、投影、光影随风格主题走（`card_fn=` 可以换成风格自己的卡片，如纸片手作的撕边纸片）。

## 1.1 材质：图示要和风格是一个质感

图示的容器（金字塔层、漏斗层、韦恩的圆、循环箭头）不是平色块，而是该风格的材质：主题里写 `skin="paper"` / `"ink"` / `"glass"`，零件就会调用 `scripts/diagram_skins.py` 把这些形状渲染成带材质的透明 PNG 当容器。**文字不在图里，仍是真文字**，叠在容器上，可以直接改。

| skin | 材质 | 用在 |
|---|---|---|
| `paper` | 撕边纸片：边缘按法线抖动、纤维白边、纸纹、投影 | 纸片手作 |
| `ink` | 水墨：边缘洇开与飞白、边缘深中间浅的墨色、横向干笔 | 东方雅集 |
| `glass` | 磨砂玻璃：半透明渐变面、左上亮右下暗的边缘亮线、外发光（深色底）或蓝影（浅色底） | 发布会 |
| `flat` | 明亮扁平：实心糖果色、圆角、无描边、彩色软影；韦恩的圆画成一张图，重叠处是计算出的亮色，不是半透明混色 | 明亮扁平 |
| （无） | 原生形状，走主题的描边、硬投影、光影（韦恩的圆也套主题墨线和硬投影） | 船长课堂、刊物·图纸 |

注意：容器是图片，在 PowerPoint 里拉大会稍微拉伸；改字不受影响，要改层数、尺寸请改脚本参数重新生成。图片缓存在 `assets/_skin_cache/`。

环形图在有材质的风格里改成分段容器（每段是一个材质环扇形），中心字和图例是真文字，数据写在脚本的 `parts` 里；没有材质的风格仍用原生环形图（数据可在 PowerPoint 里改）。

## 1.2 一个风格里所有元素必须是同一个质感

图示、流程箭头、标签、序号圆、提示条、清单章、环形图，都要走同一套"风格语言"，不能只有一部分换了材质：

| 风格 | 语言 | 实现 |
|---|---|---|
| 船长课堂 | 墨线描边加硬投影 | 原生形状，主题 `outline` / `hard_shadow`；环形图的每段也描墨线 |
| 刊物·图纸 | 细墨线勾边，无投影 | 原生形状，主题 `poly_line` |
| 东方雅集 | 水墨 | `skin="ink"` |
| 纸片手作 | 撕边纸片 | `skin="paper"` |
| 明亮扁平 | 圆角实心糖果色加彩色软影 | `skin="flat"` |
| 发布会 | 磨砂玻璃 | `skin="glass"` |

有 `skin` 的风格里，`pill()`（标签）、`badge()`（序号圆）、`callout()`（提示条）、`chevrons()`（流程箭头）、`donut()`（环形图）都自动走材质容器。**新增或修改零件、主题后，用陈列页回归**：

```bash
python examples/gallery_parts.py <风格包目录名> <输出目录>      # 生成 4 页：流程提示清单标签 / 漏斗金字塔 / 韦恩循环 / 矩阵阵列环形图
```

把六个风格的陈列页并排看一遍，有哪个零件和旁边的质感不一样，就是还没接上主题。主题里还要定义浅色名（`sky`、`peach`、`mint`、`butter`、`pink`），零件的默认色才不会报错。

## 2 选图的规则

1. **先看内容长什么样**：有"回到起点"的，用循环；有"上下层"的，用金字塔；有"两个维度"的，用矩阵；有"几项并列"的，用阵列；有"重叠"的，用韦恩。
2. **一份稿子至少用上 3 种图示**，且相邻两页不用同一种。全部是卡片的稿子，要回头检查是不是丢了结构。
3. **图示里的字不超过两层**：节点标题加一行说明；说明放不下就放到右侧或备注里。
4. 图示里的字仍然遵守最小字号（上台讲 ≥ 18pt）和对比度。零件的小字默认 18–20pt。
5. 图示零件不替代"人在讲"：一页一个图，讲一个意思。

## 3 参数速查

- `cycle_ring(s, center, rx, ry, items, node=(230, 92), centre_text=None, colors=None, card_fn=None)`：椭圆循环，items=`[(标题, 说明)]`，3–5 个节点最稳。
- `pyramid(s, rect, levels, colors=None, size=22, desc_size=18, side=True)`：levels 从上到下 `[(标题, 说明)]`；说明在右侧用细线引出。
- `funnel(s, rect, stages, colors=None, narrow=0.42)`：stages 从上到下。
- `matrix(s, rect, cells, rows=2, cols=2, col_labels=None, row_labels=None, x_axis=None, y_axis=None, card_fn=None)`：cells 按行排列 `[(标题, 说明或 None)]`。
- `array_grid(s, rect, items, cols=4, colors=None, size=20, numbered=True, card_fn=None)`：items=`[标题]` 或 `[(标题, 说明)]`。
- `venn(s, center, r, labels, mid=None, colors=None)`：2 或 3 个圆；`mid` 是交集处的文字。
- `donut(s, rect, parts, centre=None, colors=None)`：parts=`[(名称, 数值)]`，右侧自动写图例。
