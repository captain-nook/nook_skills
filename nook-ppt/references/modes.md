# 两类 PPT

先问清楚是哪一类，它决定字数、留白、动效、备注和底色。

## 1 上台讲（talk）

目标是"中高端"：一个视觉锚点加一句标题，最多一两个关键词，解释放进备注里的讲稿。不追求零字。"见山不是山"式的零字做法（一个远山层叠的动画、一个疑惑的人物，全程靠嘴讲）是今后的目标，只在用户明确要求、且素材到位时做。

页面角色（每页必须选一个）：

| 角色 | 载体 | 文字预算（含标题） |
|---|---|---|
| 锚点页 | 一张图 / 一个大字 / 一个场景 / 人物加表情 | ≤ 20 字 |
| 结构页 | 流程图、对比、时间线、分层，标签而不是句子 | ≤ 60 字 |
| 数据页 | 一个图表或一个大数字 | ≤ 40 字 |
| 素材页 | 用户的照片、截图、视频 | ≤ 30 字 |
| 章节页 | 大标题加一句 | ≤ 24 字 |

- 页面上出现的文字，讲师都要说到；说不到的字删掉。
- 讲稿写进备注。一页的讲稿对应一个"台词起句"，方便对稿。
- 留白：内容占页面的比例不超过约 45%（量化检查，见质量清单）；一页只有一个视觉重点。
- 动效：每个讲点点击一次（`beat`）。同一个讲点里的几个元素自动依次出现。一页的讲点不超过 5 个。
- 切换：相邻页之间常驻的元素（人物、装饰、进度条）用平滑切换，同名对象。
- 底色：现场投影以深色为主。字号：正文不小于 24pt，标签不小于 18pt；衬线体用粗一点的字重。

## 2 给别人看（read）

目标是"比较好看的 PDF 文档"：读得懂、排得整齐、风格统一。

- 字数不作硬要求；留白不作硬要求。
- 不加动效；切换用朴素淡入；导出 PDF 时所有元素都在。
- 底色以浅色为主（打印、阅读友好）。字号：正文不小于 14pt。
- 备注可选。

## 3 同一份内容出两个版本

演讲版是锚点加讲稿；阅读版是把讲稿的要点排成文字。两个版本共用同一份提纲（`plan.json`），只是模式和文字预算不同。用户只要一类就只做一类。
