# 许可与来源说明

## 代码
本 skill 的脚本（`scripts/`、`examples/`、各风格包里的 `theme.py` / `kit.py` / `parts.py` / `make_bg.py`）随仓库的许可发布（见仓库根目录 LICENSE）。

## 字体
- **字体文件都不随库提供**，请自行从官方渠道下载安装，下载地址见 `assets/fonts/README.md`：思源宋体（Source Han Serif CN）、霞鹜文楷（LXGW WenKai）为 SIL OFL 协议；MiSans 有自己的使用许可，以官方页面为准。
- 缺哪个字体，主题就自动退回微软雅黑，版式不会坏，只是字形不同。
- 微软雅黑是 Windows 自带字体，不随库发布。
- 字体需要装进系统，PowerPoint 才能显示；量字所用的字体文件由主题依次查找：环境变量 `NOOKPPT_FONT_DIR` → 当前用户字体目录 → 系统字体目录 → 本库 `assets/fonts/`（你可以把下载的字体文件放在这里）。

## 图片、素材库与船长 IP
- 素材库（`assets/library/`）、各风格包的素材（`deco/`、`tips/`、`raw/`、底图）由作者用本地 ComfyUI 的 Qwen Image 2.1 生成（提示词骨架在各风格包的 `prompts.md`，出图任务在 `jobs_*.json`），其使用条件以 Qwen-Image-2.1 官方仓库的许可为准，商用前请自行核对。部分底图由代码生成（`make_bg.py`、`diagram_skins.py`）。
- **船长（Captain Nook）是作者原创的 Q 版角色**，随库提供其提示表情、姿势和 Logo，用于船长课堂、明亮扁平、纸片手作三套风格。角色形象的版权归作者；用本 skill 做你自己的演示文稿可以使用，要把角色素材本身单独转发、二次发行或商用，请先联系作者。可以完全不用船长，替换方法见 `README.md`。
- 这些素材都可以由用户用自己的 ComfyUI 或任意图像 API 重新生成，不依赖本库提供的图。
- 用户自己提供的照片、截图、Logo、视频，版权归用户；skill 只做遮罩、裁切、底衬和边框，不改内容，也不用生成图冒充事实类素材。

## 样片内容
`examples/` 里的样片内容用公认的方法和规律（费曼学习法、PARA、艾宾浩斯遗忘曲线、四象限）以及作者的《公众号运营宝典》方法论。遗忘曲线的数据取自艾宾浩斯 1885 年记忆实验的常见引用值（节省率），页内已注明。
